## 🍲 What does Gastronomicon do?

Gastronomicon expands Slimefun with **additional foods, ingredients, recipes, and food-related progression**. It works especially well alongside ExoticGarden, giving players more uses for custom crops and ingredients.

Key behavior includes:

- a large collection of additional custom foodstuffs;
- optional **ExoticGarden** integration;
- optional **DynaTech** crop/automation integration;
- configuration switches for supported integrations;
- a developer API for custom food content.

ExoticGarden is not strictly required, but it is strongly recommended for the intended food ecosystem.

## 🧪 Slimefun Legacy maintenance

This fork focuses on keeping Gastronomicon working on modern Paper and Slimefun Legacy while preserving recipes, items, integrations, API behavior, and saved-data identity wherever practical.

Server owners should back up established worlds and plugin data before replacing production builds.
